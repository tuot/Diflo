# DiffZen Meld 式文件对比会话设计

## 文档状态

本设计取代此前“加载两个文件后只读展示 Diff”的交互模型。已有文件读取、行级 Diff、对齐渲染与同步滚动能力继续复用，但产品核心升级为可编辑、可保存、可按差异块合并的对比会话。

## 产品目标

第一版复刻 Meld 文件对比的核心工作流，而非复刻其视觉：用户可以从文件或空白内容创建双栏对比，在两侧直接编辑，实时查看差异，按差异块导航和双向应用内容，并将任意一侧保存到文件。

界面采用原生 macOS 设计。第一版只支持单窗口、单个双向对比会话。

## 第一版范围

包含：

- 启动页创建空白对比，或选择左右两个文件创建对比。
- 左右两侧均可单独打开、替换、编辑、保存和另存为。
- 编辑后实时重新计算行级 Diff。
- 整行差异高亮、原始行号和同步垂直滚动。
- 上一个、下一个差异块导航。
- 中间连接带展示差异块对应关系。
- 从左向右、从右向左应用单个差异块。
- 删除当前侧的差异块。
- 右侧差异缩略图展示整份文档的差异分布并支持定位。
- 撤销、重做、未保存状态和关闭/替换确认。
- 展示并尽量保留文件编码与换行符。

不包含：

- 目录对比。
- 三方对比或冲突解决模式。
- Git 等版本控制集成。
- 多标签或多个并行对比会话。
- Meld 文本过滤器、同步点和正则忽略规则。
- 字符级差异高亮；第一版保持整行高亮。

## 页面流程

### 启动页

窗口打开后显示“新建对比”。文件对比是唯一可用类型；目录和版本控制入口不出现，避免展示不可用功能。

用户可以：

1. 分别选择左右文件，再点击“开始对比”。
2. 只选择一侧文件，另一侧以空白缓冲区进入。
3. 点击“空白对比”，创建两个空白缓冲区。

空白缓冲区显示为“未命名 1”和“未命名 2”。

### 对比工作区

工作区由全局工具栏、左右文件栏、双编辑器、中间差异连接带、差异缩略图和底部状态栏组成。

全局工具栏提供返回启动页、上一个/下一个差异、撤销/重做和交换两侧。左右文件栏分别提供打开、保存、另存为及当前文件名。未保存缓冲区的文件名显示修改标记。

编辑器使用等宽字体、固定视觉行高和原始行号。自动换行默认关闭，确保左右虚拟行稳定对齐；水平滚动独立，垂直滚动同步。

中间连接带按差异块绘制对应关系。每个差异块显示适用的 `→`、`←` 和删除操作；连接带不是装饰层，而是合并操作的入口。

差异缩略图按全文比例标出新增、删除和修改区域。点击缩略图位置滚动到相应差异块。

底部状态栏分别显示编码、换行符、文本模式，以及当前光标的行列位置。

## 会话与缓冲区模型

`ComparisonSession` 是 `@MainActor @Observable` 的界面状态源，拥有两个 `EditorBuffer`、当前 `DiffDocument`、选中的差异块 ID，以及加载、计算、保存和错误状态。

每个 `EditorBuffer` 保存：

- `text: String`：编辑中的完整文本。
- `url: URL?`：空白缓冲区为 `nil`。
- `displayName: String`：文件名或未命名标题。
- `encoding: TextEncoding`：读取和保存使用的编码。
- `lineEnding: LineEnding`：LF、CRLF 或 CR。
- `hasTrailingNewline: Bool`：文件尾换行状态。
- `isDirty: Bool`：是否存在未保存修改。
- `revision: Int`：每次文本变化递增，用于丢弃过期 Diff。
- `lastKnownModificationDate: Date?`：保存前检测外部修改。

空白缓冲区默认使用 UTF-8、LF、无文件尾换行。

## Diff 文档与差异块

现有 `DiffRow` 保留为渲染单元，同时增加 `DiffHunk` 和 `DiffDocument`。

`DiffHunk` 保存稳定 ID、差异类型、左右原始行范围和对齐后虚拟行范围。差异类型使用不带方向歧义的 `leftOnly`、`rightOnly` 和 `modified`；连续的同类差异行组成一个差异块。稳定 ID 由左右 revision、行范围和内容摘要生成，仅用于当前 Diff 版本内的选择与命令定位。

`DiffDocument` 保存等长虚拟行、差异块数组、计数和尾部换行差异。导航、连接带、缩略图和合并命令只能消费 `DiffDocument`，不各自推导 Diff。

## 实时 Diff 数据流

```text
NSTextView 编辑
  ↓
EditorBuffer.text / revision 更新并标记 isDirty
  ↓ 150 ms 防抖
DiffCoordinator actor 接收左右不可变快照
  ↓
LineDiffEngine 计算 DiffRow 和 DiffHunk
  ↓
ComparisonSession 校验左右 revision
  ↓
更新高亮、连接带、缩略图和当前差异选择
```

新编辑发生时取消尚未开始的防抖任务。已经运行的标准库 Diff 无法强制中断，但旧结果因 revision 不匹配而不得写回界面。

继续沿用单文件 10 MB、20,000 行的第一版限制。超过限制时拒绝加载；空白编辑器超过限制时保留文本但暂停 Diff，并展示明确状态。

## 编辑与 Undo

左右 `NSTextView` 可编辑，并各自使用原生 `UndoManager`。AppKit bridge 通过 delegate 将真实文本变化发送给 `ComparisonSession`；session 更新 AppKit 内容时使用重入保护，避免形成回调循环或破坏选区。

普通输入、粘贴、删除和差异块应用都必须注册到对应编辑器的撤销栈。撤销或重做同样触发新一轮实时 Diff。

## 差异块操作语义

从源侧向目标侧应用差异块时，不根据全局“新增/删除”名称猜测方向，而直接读取该差异块的源侧与目标侧行范围：

- 源侧与目标侧都有内容：用源侧行范围替换目标侧对应行范围。
- 源侧有内容、目标侧范围为空：把源侧内容插入目标侧锚点位置。
- 源侧范围为空、目标侧有内容：删除目标侧对应内容。

删除当前侧差异块只修改当前侧缓冲区：独有内容被删除；modified 内容删除后会在下一次 Diff 中重新分类。每次操作基于当前 `DiffDocument`；如果编辑已使 revision 变化，旧差异块命令失效并等待新 Diff，不能作用于过期行范围。

操作完成后目标侧保持焦点，选中被修改范围，并在新 Diff 产生后选择距离原位置最近的剩余差异块。

## 文件读取与保存

读取继续使用 security-scoped URL、字节/行数限制、BOM、严格 UTF-8 和 Foundation 无损编码检测。读取时记录编码、主要换行符、尾部换行状态和文件修改时间。

保存时：

1. 将编辑器内部统一的 `\n` 转回缓冲区记录的换行符。
2. 使用原编码进行无损编码；无法编码时提示改用 UTF-8，不静默替换字符。
3. 写入同目录临时文件后原子替换目标文件。
4. 成功后刷新修改时间并清除 `isDirty`。

未命名缓冲区的“保存”进入另存为。替换文件、返回启动页或关闭窗口前，如果任一缓冲区未保存，分别提供保存、不保存和取消。目标文件自加载后被外部修改时，保存前提供重新加载、覆盖和取消。

## AppKit 视图结构

`EditableDiffContainerView` 通过单个 `NSViewRepresentable` 拥有左右 `NSTextView`、两个 `NSScrollView`、`ChangeGutterView` 和 `DiffOverviewView`。集中持有它们可以统一坐标系、滚动同步、选区和通知生命周期。

`ChangeGutterView` 根据两侧 layout manager 的行矩形绘制差异块连接形状及操作按钮。第一版关闭自动换行，因此逻辑行、虚拟行和视觉行一一对应。

`DiffOverviewView` 只消费差异块在虚拟行总数中的比例，不读取编辑器文本。滚动时显示当前可见范围；点击时转换为目标纵向偏移。

## 错误处理

- 读取失败、无权限、二进制文件、无法识别编码和超限文件显示可恢复错误，不清除已有缓冲区。
- 保存失败保留 `isDirty`，原文件不被部分覆盖。
- Diff 暂停或失败不阻止继续编辑和保存，但连接带与合并按钮进入不可用状态。
- 过期差异块命令不执行，并等待最新 Diff，而不是猜测新的行范围。
- 用户取消打开、保存或关闭确认时保持当前会话不变。

## 测试策略

核心模型和命令遵循红—绿—重构：

- `EditorBuffer`：编辑、dirty、编码、换行符和 revision。
- `DiffHunkBuilder`：连续行成块、左右范围、重复行和不等长替换块。
- `ApplyHunkCommand`：替换、插入、删除三种范围组合的双向应用，以及过期 revision 拒绝。
- `DiffCoordinator`：防抖、旧结果丢弃和超限暂停。
- `TextFileWriter`：UTF-8/UTF-16、LF/CRLF、尾换行、原子保存和不可编码内容。
- `ComparisonSession`：打开、替换、保存、交换、导航和未保存状态。

AppKit 集成测试覆盖文本 delegate 回传、程序化更新不回环、UndoManager、同步滚动、连接带命中测试和缩略图定位。

UI 烟测覆盖两条主路径：

1. 空白对比 → 两侧编辑 → 出现差异 → 应用差异块 → 保存。
2. 选择两个文件 → 导航差异 → 修改 → 关闭时保存确认。

## 验收标准

- 无需文件即可进入两个可编辑的空白缓冲区。
- 输入停止约 150 ms 后，差异高亮、连接带、缩略图和计数更新。
- 上一个/下一个差异顺序稳定并自动滚动到可见位置。
- 左右应用替换、插入、删除差异块后，目标文本符合范围语义且可撤销。
- 空白和已有文件均可保存；保存保留选定编码、换行符和尾部换行。
- 未保存内容不会因返回、替换或关闭而静默丢失。
- 快速连续编辑时旧 Diff 不覆盖新内容。
- 第一版文件上限内编辑保持响应；Diff 运行不阻塞主线程。
